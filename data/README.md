# Data

This directory contains small, versioned datasets that are part of the research record.

## `historical_shots_staging.csv`

The original manual transcription from handwritten espresso notes. Keep this file as the immutable/auditable transcription baseline.

Important semantics:

- row order is chronological and must be preserved;
- blank cells mean unknown/unreadable values and must not be silently imputed in the staging source;
- `grinder_output_g` is the measured output of the grinder, not necessarily the dose that was brewed;
- historical shots were generally corrected to approximately the target puck dose before brewing when `dose_correction_mode=TO_TARGET`;
- `puck_dose_g=18.0` for those rows is therefore an approximate controlled target, not a second high-precision measurement;
- `transcription_status` and `notes` record uncertainty in the original transcription;
- known bean/session boundaries must remain explicit.

Do not edit this file merely to make a model fit better. Corrections belong in the corrected dataset so the original transcription remains reviewable in Git history.

## `historical_shots_corrected.csv`

This is the **authoritative historical dataset for analysis and model development**. It starts from the staging transcription and incorporates later user-supplied corrections/recovered entries that could not be established reliably from the original image alone.

Use this file, not the staging file, for current historical analyses, notebooks, rolling backtests, and model-gap analysis unless a task explicitly concerns transcription uncertainty itself.

Known bean identities:

- sequences 1–39: `cafe_intencion_espresso_intensivo` — Café Intención Espresso Intensivo;
- sequences 40–51: `rewe_bio_espresso_ganze_bohnen_1000g` — REWE Bio Espresso ganze Bohnen, 1000 g.

The corrected file keeps provenance in `notes` where values were supplied or corrected after the initial transcription. Remaining genuinely missing measurements stay blank. Approximate source measurements remain marked `approximate` rather than being silently promoted to exact values.

The current REWE Bio Espresso is also the bean expected for the first prospective/live-data phase, but new live observations should be stored in the runtime database rather than appended to this historical CSV.

## Runtime data

Local SQLite databases, temporary exports, model caches, and other runtime state are intentionally ignored by Git. Only small datasets with clear provenance and research value should be committed here.
